# Logos dos parceiros

As peças especiais (que valem 2 pontos) usam estes arquivos:

| Parceiro   | Arquivo            |
|------------|--------------------|
| Buddemeyer | `buddemeyer.png`   |
| Karsten    | `karsten.png`      |
| Döhler     | `dohler.png`       |
| Teka       | `teka.png`         |

- Use **PNG com fundo transparente**, de preferência na versão colorida para fundo branco.
- Corte as sobras: quanto menos borda vazia, maior o logo aparece na peça.
- Uns 600 px de largura bastam.
- Enquanto um arquivo não existir, a peça mostra o nome da marca escrito.

Para trocar ou incluir parceiros, edite a lista `PARTNERS` no começo do script em `index.html`.
